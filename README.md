# ARKANOID — Инструкция пользователя

# 1. Назначение программы

Arkanoid — консольная аркадная игра, разработанная на языке C# в рамках лабораторной работы №3.

Цель игры — уничтожить все кирпичи на игровом поле, управляя платформой и отбивая движущиеся мячи.

В программе реализованы система начисления очков, дополнительные бонусы, поддержка нескольких одновременно движущихся мячей, а также сохранение и восстановление игрового состояния.

# 2. Системные требования

Для запуска опубликованной версии программы необходимы:

- Операционная система Windows 10 или Windows 11.
- Компьютер с архитектурой x64.
- Клавиатура для управления игрой.

Программа опубликована в автономном режиме для Windows x64.

Дополнительная установка .NET для запуска опубликованной версии не требуется.

# 3. Запуск игры

Для запуска программы необходимо:

1. Открыть папку с опубликованной версией игры.
2. Найти исполняемый файл `Laba_3.exe`.
3. Запустить его двойным щелчком мыши.
4. Дождаться появления начального меню.
5. Нажать любую клавишу для начала игры.

Если программа обнаружит ранее созданное сохранение, пользователю будет предложено продолжить предыдущую игру или начать новую.

# 4. Главное меню

При запуске программы отображается главное меню.

Если сохранённая игра отсутствует, пользователь может начать новую игру.

Если файл сохранения существует, становятся доступны следующие действия:

- **Продолжить игру** — загрузить последнее сохранённое состояние.
- **Начать новую игру** — начать прохождение заново.

При выборе продолжения восстанавливается состояние игрового поля на момент последнего сохранения.

# 5. Управление игрой

Управление игровой платформой осуществляется с помощью клавиатуры.

| Клавиша        | Назначение 
| A              | Перемещение платформы влево 
| D              | Перемещение платформы вправо 
| Стрелка влево  | Перемещение платформы влево 
| Стрелка вправо | Перемещение платформы вправо 
| Q              | Сохранение текущей игры и выход 

Платформа перемещается горизонтально и не может выходить за границы игрового поля.

# 6. Правила игры

Игровое поле содержит кирпичи, платформу и движущиеся мячи.

Основная задача игрока — уничтожить все кирпичи, используя платформу для изменения направления движения мяча.

Основные правила:

1. Мяч автоматически перемещается по игровому полю.
2. При столкновении с боковыми и верхней границами поля мяч меняет направление движения.
3. При попадании в платформу мяч отскакивает вверх.
4. При столкновении с кирпичом тот уничтожается.
5. За уничтожение каждого кирпича начисляются очки.
6. Некоторые кирпичи могут оставлять после уничтожения бонусы.
7. Игрок может одновременно управлять платформой, отбивая несколько мячей.
8. Если мяч падает за нижнюю границу игрового поля, он теряется.

Игра продолжается, пока на поле остаётся хотя бы один активный мяч.

# 7. Система бонусов

При уничтожении кирпича существует вероятность выпадения бонуса. Вероятность составляет 25%.

В игре предусмотрены три вида бонусов.

# 7.1. Увеличение платформы

При подборе бонуса ширина платформы увеличивается на 6 символов.

Максимальная ширина платформы составляет 24 символа.

# 7.2. Увеличение мяча

При подборе бонуса размер мяча увеличивается.

Увеличенный мяч занимает больше символов при отображении на игровом поле.

# 7.3. Дополнительные мячи

При подборе бонуса на игровом поле появляются два дополнительных мяча.

Каждый мяч перемещается независимо от остальных. Потеря одного мяча не завершает игру, если на поле остаются другие активные мячи.

# 8. Сохранение и загрузка игры

Программа поддерживает сохранение и восстановление игрового состояния с использованием JSON-сериализации.

# 8.1. Сохранение

Для сохранения текущего состояния необходимо нажать клавишу `Q`.

После этого программа записывает данные в файл `savegame.json` и завершает работу.

Сохраняются:

- координаты и скорость всех мячей;
- размер и активность мячей;
- положение и ширина платформы;
- положение и состояние кирпичей;
- координаты и типы бонусов;
- набранные очки;
- размеры игрового поля.

# 8.2. Загрузка

При следующем запуске программа проверяет наличие файла сохранения.

Если сохранение найдено, пользователю предлагается продолжить игру.

При загрузке восстанавливаются ранее сохранённые игровые объекты и их параметры.

**Важно:** для корректного сохранения необходимо завершать игру клавишей `Q`. Принудительное закрытие окна не гарантирует сохранение текущего состояния.

Файл `savegame.json` необходимо хранить вместе с программой в той рабочей директории, откуда выполняется запуск.

# 9. Условия завершения игры

В игре предусмотрено два основных исхода.

**Победа:**

Игрок одерживает победу после уничтожения всех кирпичей на игровом поле.

**Поражение:**

Игра завершается поражением, если все мячи покинули игровое поле через нижнюю границу.

После завершения игры программа отображает соответствующее сообщение.

# 10. Возможные проблемы

| Проблема | Возможное решение |
|---|---|
| Программа не запускается | Проверить, что используется версия для Windows x64 |
| Не загружается сохранение | Проверить наличие и целостность `savegame.json` |
| Управление не работает | Проверить, активно ли окно игровой консоли |
| Игра завершилась | Начать новую игру или загрузить сохранение, если оно имеется |
